入口 `backend/main.go` 使用 `iris.New()` 创建应用，注册 HTML 模板引擎（根布局为 `shared/layout.html`）、静态资源目录 `/assets` 指向 `web/assets`，并通过全局错误钩子 `OnAnyErrorCode` 统一跳转到 `shared/error.html`。路由按业务域划分：`/product` 和 `/order` 各自通过 `app.Party` + `mvc.New` 构建独立 MVC 模块，每个模块将领域 Service（`services.IProductService`、`services.IOrderService`）注入到对应 Controller，并调用 `Handle(new(controllers.XxxController))` 注册控制器方法。控制器仅负责解析表单、调用 Service、返回 `mvc.View` 或重定向，数据访问下沉至 `repositories` 层，由 `main.go` 在启动时组装依赖链（Repository → Service → Controller）。视图位于 `web/views`，按模块分目录（`product/`、`order/`），公共布局与错误页放在 `shared/`；前端静态资源（CSS/JS/图片/第三方库）集中在 `web/assets`。
