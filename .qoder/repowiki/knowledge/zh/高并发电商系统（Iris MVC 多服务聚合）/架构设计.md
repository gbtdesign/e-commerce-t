根目录按分层组织：common_lib 提供跨模块共享工具，datamodels 定义领域实体，repositories 实现 MySQL 持久化，services 编排业务逻辑；backend_admin_web 与 frontend_shop_web 作为两个独立的 Iris MVC Web 进程分别暴露后台管理与前台站点接口；root_utilities 提供订单消费者、分布式权限校验与秒杀数量控制的三个独立可执行程序，作为下单链路的前置验证与异步消费入口。info 文件记录 wrk 压测命令，imooc 文件列出 model→repositories→services→controllers→views 的分层顺序，体现该仓库遵循的领域驱动分层约定。
