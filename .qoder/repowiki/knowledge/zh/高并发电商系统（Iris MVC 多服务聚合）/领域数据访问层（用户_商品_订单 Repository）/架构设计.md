本模块按领域实体拆分为三个文件：user_repository.go、product_repository.go、order_repository.go，每个文件定义一个领域接口（IUserRepository / IProduct / IOrderRepository）及其具体实现结构体（UserManagerRepository / ProductManager / OrderMangerRepository），并通过 NewXxx(table, *sql.DB) 工厂函数构造。
- 依赖方向单向向下：本包仅依赖 imooc-product/common（封装 NewMysqlConn、GetResultRow/Rows、DataToStructByTagSql 等通用 DB 工具）与 imooc-product/datamodels（领域模型），不反向被 common 或 datamodels 引用。
- 连接管理：每个实现通过 Conn() 方法懒加载 mysqlConn，若未传入则调用 common.NewMysqlConn() 获取；table 字段为空时回落到默认表名（user/product/order）。
- SQL 编写：使用 database/sql 原生的 Prepare + Exec/Query，参数以 ? 占位符传递；查询结果统一经 common.GetResultRow(s) 转为 []map[string]string，再通过 common.DataToStructByTagSql 反序列化为 datamodels 结构体。
- 错误处理：读取不到记录时返回空结构体并配合 errors.New 包装业务错误（如“用户不存在”），写操作失败直接透传 error。
