模块以 `main.go` 为应用入口，启动 Iris HTTP 服务器并挂载两个 MVC Party：`/user` 与 `/product`。
- 分层结构：`web/controllers` 暴露控制器（`UserController`、`ProductController`），通过字段注入依赖 `services.IUserService` / `services.IProductService` / `services.IOrderService` 以及 `rabbitmq.RabbitMQ`，不直接访问数据库；数据层由上层 `repositories` 与 `services` 包提供。
- 中间件：`middleware/auth.go` 的 `AuthConProduct` 在 `/product` 路由前校验 Cookie `uid`，未登录则重定向到 `/user/login`。
- 视图与静态资源：模板引擎使用 `iris.HTML`，根布局为 `shared/layout.html`，错误页为 `shared/error.html`；静态文件通过 `app.StaticWeb` 暴露 `/public` 与 `/html` 目录。
- 双入口：`main.go` 启动完整业务服务（8082 端口），`productMain.go` 仅托管静态资源（80 端口），用于部署已生成的静态页面。
- 静态化能力：`ProductController.GetGenerateHtml` 读取 `views/template/product.html`，渲染后写入 `web/htmlProductShow/htmlProduct.html`，再由 `/html` 静态路由对外暴露。
