- 控制器通过结构体字段注入依赖（如 `Service`、`ProductService`、`OrderService`、`RabbitMQ`、`Session`），而非全局变量或构造函数传参。
- HTTP 处理器返回类型遵循 Iris MVC 约定：渲染视图返回 `mvc.View`，纯响应返回 `[]byte` 或 `mvc.Response`。
- 日志统一通过 `ctx.Application().Logger()` 输出，错误路径使用 `Debug`/`Error` 级别记录。
- 用户身份通过 Cookie `uid` 传递，并在 `/product` 路由前由 `AuthConProduct` 中间件校验。
