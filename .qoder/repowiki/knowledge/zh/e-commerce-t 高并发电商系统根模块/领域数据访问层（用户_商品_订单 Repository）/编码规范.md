- 每个领域实体采用「接口 + 结构体 + 工厂构造函数」三段式组织：先声明 I* 接口，再定义 XxxManager/XxxManagerRepository 结构体持有 table 与 mysqlConn，最后由 NewXxx(table, db) 返回接口实例。
- 所有公开方法在执行 SQL 前先调用 Conn() 确保连接就绪，并在 Conn() 内部完成 mysqlConn 懒初始化与 table 默认值填充。
- CRUD 方法的 SQL 字符串通过拼接 u.table 与固定片段构建，主键条件统一使用 strconv.FormatInt(id, 10) 转字符串后拼接。
- 查询单行使用 common.GetResultRow(rows)，查询多行使用 common.GetResultRows(rows)，随后统一调用 common.DataToStructByTagSql 将 map 反序列化为 datamodels 结构体。
- 读不到记录时返回空结构体指针并配合 errors.New 抛出业务语义错误（如“用户不存在！”），写操作失败则直接返回底层 error。
