本模块由三个独立的 `package main` 程序组成，各自承担下单链路中的一个职责：
- `consumer.go`：作为 RabbitMQ 消费者进程，初始化 MySQL 连接后构建 `repositories.ProductManager`/`OrderMangerRepository` 及对应 `services`，通过 `rabbitmq.NewRabbitMQSimple("imoocProduct")` 订阅并消费订单消息。
- `validate.go`：作为 HTTP 服务（端口 8083），实现 `/check`、`/checkRight` 两个接口；内置基于 Cookie 的身份校验（`Auth` → `CheckUserInfo` → `encrypt.DePwdCode`）和一致性哈希路由的分布式权限检查（`AccessControl.GetDistributedRight`，本地节点直接查内存 map，跨节点通过内网 HTTP 代理转发到本机 `/checkRight`）；业务校验通过后调用 `getOne:8084/getOne` 进行数量控制，再经 RabbitMQ 发送下单消息。
- `getOne.go`：作为独立的限流服务（端口 8084），暴露 `/getOne`，使用全局 `sync.Mutex` + 计数器按每 100 次请求允许一次真实扣减的方式模拟秒杀库存控制。
依赖方向单向：`validate.go` 调用 `getOne.go` 与 `rabbitmq`，`consumer.go` 仅消费消息，三者之间无共享状态，通过进程间 HTTP/RabbitMQ 通信协作。
